# MedAssist AI — DeepSeek + LangChain Medical RAG Chatbot

## Run
1. `pip install -r requirements.txt`
2. Copy `.env.example` to `.env`.
3. Add your DeepSeek API key.
4. Open `MedAssist_AI_DeepSeek.ipynb`.
5. Run cells from top to bottom.

## Safety
Educational/portfolio project only. Not a medical device and not for diagnosis, prescribing, or emergency management.
